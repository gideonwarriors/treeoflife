# 生命樹基督教會網站

主網站只有 `index.html` 一個檔案：HTML、CSS、JavaScript、教會照片、標誌、牧師照片與組織圖全部內嵌。直接用瀏覽器開啟即可閱讀，也適合 GitHub Pages。沒有建置程序、外部字型或付費服務。影音卡片在點選後另開 YouTube；頁面本身沒有外部播放器或縮圖依賴。

## 正式網站與發布

- 網站：https://gideonwarriors.github.io/treeoflife/
- 儲存庫：https://github.com/gideonwarriors/treeoflife
- 發布來源：`main` 分支根目錄，由 GitHub Pages 建置。
- 目前版本見 `VERSION` 與網站頁尾；每版附 Git tag 和 `CHANGELOG.md`。
- 四段版本依序進位：`1.0.0.1 → 1.0.0.2 → … → 1.0.0.9 → 1.0.1.0`。後三段為 0–9，第一段無上限。
- 網站維護完成後由本機發布流程自動升版並推送；無內容修改不升版。

## 設計與功能

全站依教會背心採用白色、深藍、寶藍與淺藍配色，綠色只作為兩側少量枝葉點綴，並融入活水波紋，首頁以十字架與經文呈現耶穌基督為教會元首，並以門徒訓練與大使命為核心。首頁合照已從 HTML 移除。「異象與呼召」是首頁首要內容，並保留黃思義牧師完整呼召文字。網站包含門徒訓練、牧者簡介、沿革時間軸、三個小組、YouTube 影音、組織圖、獻堂感恩禮拜與聚會資訊。

支援桌機與手機、手機選單、原生展開內容、組織圖與邀請卡放大視窗、鍵盤操作及減少動態效果偏好。放大組織圖後可捲動，按 Esc 即可關閉。

日後更新，可編輯 `index.html` 裡的文字。大量圖片資料是 `data:image/...;base64,...`，請勿手動修改其中字元。可讀的開發模板與重建程式保留於同層上方的 `website-work` 資料夾，該資料夾含整理中的來源資訊，**不需要上傳**。
